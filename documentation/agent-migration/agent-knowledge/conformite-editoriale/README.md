# Conformité éditoriale

Ce dossier regroupera les règles et références utilisées par l'agent pour analyser la conformité éditoriale des fiches.

Il correspond au groupe `ressources_conformité_éditoriale/*` identifié dans l'inventaire Letta Cloud d'Agathe.

## Contenus attendus

- Jurisprudence éditoriale.
- Règles de conformité applicables aux fiches Réfugiés.info.
- Référentiels ou taxonomies utiles, dont Formacode.
- Notes de décision métier utiles à l'arbitrage de conformité.

## Notes de migration

Les contenus historiques liés à l'ancien périmètre RCO doivent être relus avant migration. Seules les règles encore utiles au flux Data Inclusion → Réfugiés.info doivent être conservées comme références actives.
