# Langage clair

Ce dossier regroupera les ressources utilisées par l'agent pour transformer et rédiger les contenus Réfugiés.info en langage clair.

Il correspond au groupe `ressources_langage_clair/*` identifié dans l'inventaire Letta Cloud d'Agathe.

## Contenus attendus

- Chartes éditoriales Réfugiés.info.
- Lexiques administratifs et simplifications de vocabulaire.
- Guides de transformation rédactionnelle.
- Références de personas ou de publics cibles utiles à la rédaction.
- Schémas de fiche dispositif utilisés comme support de rédaction.

## Notes de migration

Les chemins d'origine exportés depuis Letta Cloud doivent être conservés dans la provenance (`source_path`, `original_file_name`, manifeste) pour garder la traçabilité.

Les chemins cible versionnés peuvent corriger une coquille évidente. Les corrections déjà appliquées dans ce dossier sont documentées dans le [README du corpus](../README.md#convention-de-nommage).
