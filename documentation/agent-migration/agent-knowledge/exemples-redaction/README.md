# Exemples de rédaction

Ce dossier regroupera les exemples de fiches utilisés pour guider l'agent dans ses transformations rédactionnelles.

Il correspond au groupe `ressources_exemples_redaction/*` identifié dans l'inventaire Letta Cloud d'Agathe.

## Contenus attendus

- Versions initiales de fiches.
- Versions finales publiées ou validées.
- Exemples avant/après permettant d'illustrer les transformations attendues.

## Notes de migration

Plusieurs PDF d'exemples n'avaient qu'un seul chunk indexé dans Letta Cloud. Leur qualité d'extraction devra être vérifiée avant de les utiliser comme source fiable pour `qmd`.
