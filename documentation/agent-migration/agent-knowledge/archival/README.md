# Mémoire archivée

Ce dossier regroupera les éléments de mémoire archivée qui restent utiles après tri.

Il ne doit pas contenir toute la mémoire archivée brute : seuls les éléments ayant une valeur métier, historique ou de jurisprudence doivent être conservés.

## Contenus attendus

- Historique utile de l'agent, dont le renommage Edwige → Agathe.
- Décisions ou notes produit encore pertinentes.
- Jurisprudence éditoriale issue des anciennes analyses.
- Notes OEPRE ou RCO conservées uniquement si elles éclairent le périmètre actuel.

## Notes de migration

Chaque élément archivé doit indiquer pourquoi il est conservé et s'il relève d'une référence active, d'un contexte historique ou d'un ancien périmètre à ne pas réappliquer automatiquement.
