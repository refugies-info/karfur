# Métadonnées

Ce dossier regroupera les références utilisées par l'agent pour produire et valider les métadonnées Réfugiés.info.

Il correspond au groupe `ressources_metadatas/*` identifié dans l'inventaire Letta Cloud d'Agathe.

## Contenus attendus

- Mapping RCO vers métadonnées Réfugiés.info.
- Mapping Data Inclusion vers métadonnées Réfugiés.info.
- Exemples de sortie `metadata_ri`.
- Schémas ou notes décrivant les valeurs attendues.
- Base de connaissance liée aux choix de métadonnées.

## Notes de migration

Les règles de métadonnées doivent rester cohérentes avec l'étape de validation déterministe prévue côté worker. Les contenus de ce dossier ne doivent pas remplacer la validation applicative.
