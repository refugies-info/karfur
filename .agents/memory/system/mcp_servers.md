# Recommended MCP Servers

## 1. MongoDB / Mongoose MCP
**Purpose**: Direct schema inspection and data querying.
**Value**: Verify migrations, check content states (dispositifs, traductions), and debug complex queries.

## 2. GitHub / Git MCP
**Purpose**: PR management and history analysis.
**Value**: Automate PR creation (stg/prod), analyze merge histories, and track feature branches.

## 3. DSFR / Accessibility MCP
**Purpose**: Compliance checks and token reference.
**Value**: Quickly lookup DSFR components, accessibility rules (RGAA 4), and Tailwind mappings.

## 4. Biome MCP
**Purpose**: Fast linting and formatting.
**Value**: Ensure code quality without running full CLI commands.
